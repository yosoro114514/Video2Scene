每一步都有可检查的结果

  1. 观察与测量

    Pi 查看 RGB 观察帧，ViPE 估计相机与深度，SAM 提供实例掩码。证据通过原始帧号对应，生成空间范围和支撑关系提议。

  2. 白模与人工采用

    Agent 提出初始布局。用户在浏览器核对、调整并保存，再采用这个版本和精修目标；后续资产继承已采用的空间约束。

  3. 作者与独立复核

    对象作者编写 Blender 代码；宿主构建、重开、渲染并检查资产，独立 critic 对照源图评估结构，必要时返修。

  4. 保存与 Blender 导出

    完成的对象成为持久资产包。保存时合入最新获准场景，通过技术验证后提交版本，再导出与保存版本一致的 Blender 和 GLB。

完成一件，就可以保存并补入下一件

对象生成可以重叠，每个场景的保存串行执行。较快对象无需等待同组所有对象完成；依赖与待保存积压决定何时启动后续任务。

资源默认／范围含义
对象任务3／1–4同时处于生成与复核流程的目标上限
对象模型名额3／1–4服务内跨项目共享的作者／critic 调用额度
Blender 执行组1／1–2共享构建、渲染及作者执行额度
场景保存每场景 1合并、验证与提交保持串行

作者整个调用保守占用 Blender 名额。对象任务数不等于同时运行的模型调用数，也不代表加速倍数；旧批次保留原模式。

连接失败后，保留已经完成的工作

任务、资产与版本

任务由服务持久管理，跨工具调用存活。操作 ID、进程身份、候选哈希和保存检查点用于查询已有工作，避免重复派发或旧场景覆盖新结果。

暂停与明确恢复

暂停会停止补位和新合并；运行中的任务按状态收尾。恢复前核对当前授权、进程和失败记录。已经成功的资产与已保存对象继续保留。

连接重试的边界

主控瞬时连接错误最多重试五次，间隔为 2／4／8／16／30 秒。对象 CLI 仅在日志证明尚未执行时重连容量拒绝；有执行或结果不明时，先核对已有结果。

当前能力范围

单目尺度通常为估计值，遮挡部分可能依赖先验。透明与反射表面、缺少纹理和覆盖不足的输入仍可能失败。示例展示不等于通用重建精度保证。

开始使用与参与开发

先运行 python -m video2scene demo 体验无需模型的编辑与导出。完整视频路线从 python -m video2scene workbench 开始，需要已配置的模型与 GPU 环境。
