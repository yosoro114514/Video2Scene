从视频到可编辑场景

  1. 导入视频，在讨论中描述房间和建模目标。
  2. Pi 查看关键帧、调用相机／深度与分割工具，构建白模。
  3. 在三维场景中核对布局，通过属性面板修改并保存。
  4. 采用当前布局后，精修选中对象，或执行整屋剩余对象精修。
  5. 在“进度与导出”中查看任务与保存版本对应的 Blender／GLB。

保存与恢复

候选通过验证后才成为保存版本。新整屋批次默认持续调度 3 个对象任务，可选 1–4；完成的资产逐个合并保存，同时按资源额度补入后续任务。暂停后等待 worker 收尾，再恢复；结果不明的调用需要先核对记录。

运行条件

完整流程需要已配置的 Blender、Pi／Codex、ViPE 和 SAM。运行 python -m video2scene check --mode workbench 检查本地条件，安装和认证限制见源码中的 docs/INSTALLATION.md 与 docs/CONFIGURATION.md。

输入与结果

适用于静态室内场景。尺度通常是估计值，遮挡区域可能由先验补全。选中的图像和文本会发送到所配置的模型服务，运行记录保存在本地输出目录。
